## 📌 ملخص البحث (Executive Summary)
تُعد "النواة" (Kernel) المكون الأساسي المسؤول عن إدارة الموارد وتنظيم الذاكرة وجدولة المعالجات والتحكم بالصلاحيات عبر نداءات النظام. يركز هذا البحث على التحليل المقارن والمفاضلات الهندسية والأمنية والأدائية بين ثلاث معماريات رئيسية:
1. **الأنوية المتجانسة (Monolithic Kernels):** تمثلها نواة **Linux**.
2. **الأنوية الهجينة (Hybrid Kernels):** تمثلها معمارية **Windows NT**.
3. **الأنوية المصغرة (Microkernels):** تمثلها أنظمة **QNX** ونواة **Zircon** من **Google Fuchsia**.

---

## 📑 فهرس موضوعات البحث

### 🔹 الفصل الأول: الإطار العام والدراسات النظرية
* المفاهيم الأساسية لبنية النواة ووظائفها (إدارة الذاكرة، العمليات، والموارد).
* أنواع الأنوية وبرامج تشغيل الأجهزة (Device Drivers).
* العزل بين وضع المستخدم (User Mode) ووضع النواة (Kernel Mode).
* آليات التعامل مع استدعاءات النظام (System Calls)، تبديل السياق (Context Switching)، والمقاطعات (Interrupts).

### 🔹 الفصل الثاني: الأنوية المتجانسة (Monolithic Kernels) - معمارية Linux
* مفهوم النواة المتجانسة المعيارية (Modular Monolithic Kernel).
* إدارة العمليات (`task_struct`) والذاكرة الافتراضية (`struct_mm` و Paging و COW).
* إدارة برامج التشغيل القابلة للتحميل (LKMs) والمخاطر الأمنية المعمارية المصاحبة لها.
* دراسة أمنية وتوسع مساحة الهجوم (مثل ثغرة *Dirty Pipe* وترقيعاتها).
* آليات الحماية الحديثة: KASLR و SELinux و eBPF و Cgroups/Namespaces.

### 🔹 الفصل الثالث: الأنوية الهجينة (Hybrid Kernels) - معمارية Windows
* نشأة وتطور معمارية Windows NT والطبقات الأساسية (Executive, Kernel, HAL).
* إدارة العمليات والذاكرة والتعامل مع برامج التشغيل في Kernel Mode.
* آليات الحماية الحديثة متعددة الطبقات: Secure Boot, VBS, HVCI, CFG, DEP, ASLR.

### 🔹 الفصل الرابع: الأنوية المصغرة (Microkernels) - معمارية QNX و Google Fuchsia
* مفهوم الأنوية المصغرة والعزل المتقدم لخدمات النظام في مساحة المستخدم (User Space).
* دراسة حالة نظام **QNX**: الجدولة في الأنظمة الزمنية (Real-Time Systems) والاتصال بين العمليات (IPC).
* دراسة حالة **Google Fuchsia**: بنية نواة **Zircon** ونموذج الأمان القائم على الإمكانيات (Capability-Based Security) و Handles.

### 🔹 الفصل الخامس: الدراسة المقارنة والتحليل الأمني والأدائي
* مقارنة شاملة للأداء وسرعة الاستجابة، الأمان، مساحة الهجوم، والعزل.
* تحليل نقاط القوة والضعف والنتائج النهائية للمفاضلة الهندسية.


## 📊 جدول المقارنة النهائي بين المعماريات

| المحور | الأنوية المتجانسة (Linux) | الأنوية الهجينة (Windows NT) | الأنوية المصغرة (QNX / Fuchsia) |

| **نوع المعمارية** | Monolithic | Hybrid | Microkernel |
| **مكان الخدمات** | عدد كبير داخل Kernel Space | مزيج بين Kernel/User Mode | معظم الخدمات في User Space |
| **الأداء** | مرتفع جداً | جيد إلى مرتفع | جيد، مع وجود تكلفة لنقل الرسائل (IPC) |
| **سرعة الاستجابة** | جيدة وتختلف حسب الحمل | جيدة للاستخدام العام | ممتازة وقابلة للتنبؤ (Real-Time) |
| **الأمان والعزل** | جيد بين العمليات والنواة | متعدد الطبقات مع تقنيات إضافية | قوي جداً وعزل كامل بين الخدمات |
| **مساحة الهجوم** | واسعة نسبيًا في Kernel Mode | واسعة نسبيًا | أقل بكثير في نطاق النواة ذي الامتيازات |
